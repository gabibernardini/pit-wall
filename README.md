# 📌 Sobre o projeto

Este trabalho apresenta o desenvolvimento de uma página web chamada PITWALL, inspirada no Grande Prêmio de São Paulo de Fórmula 1, realizado no Autódromo de Interlagos. O projeto foi desenvolvido utilizando HTML e CSS, com o objetivo de criar uma página visualmente moderna e organizada, apresentando informações sobre pilotos, equipes, classificação e venda de ingressos para a corrida.

# 🎯 Objetivo do projeto

O objetivo é desenvolver uma página web que represente o GP de São Paulo, aplicando os conhecimentos adquiridos em HTML e CSS para criar uma interface organizada, atrativa e responsiva, funcionando tanto em computadores quanto em dispositivos móveis.

# 🎨 Elementos apresentados

O projeto contém:

-Cabeçalho com menu de navegação e botão para compra de ingressos;

-Seção principal (Hero) com imagem temática de Fórmula 1;

-Informações sobre o GP de São Paulo, número de voltas e curvas;

-Cards com informações dos pilotos Charles Leclerc, Oscar Piastri, George Russell e Gabriel Bortoleto;

-Identificação das equipes por cores;

-Área de classificação com filtros para buscar pilotos e selecionar equipes;

-Tabela com posições, pilotos, equipes, vitórias, diferenças e pontos;

-Seção de ingressos com diferentes setores e seus respectivos valores;

-Formulário para preenchimento de dados pessoais e escolha de ingressos;

-Campo para envio de foto da torcida e mensagem para o piloto;

-Rodapé com identificação da aluna.

# 🛠️ Ferramentas e Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

-HTML: Estruturação dos elementos e conteúdos da página;

-CSS: Estilização, cores, fontes e organização visual;

-Google Fonts: Utilização de fontes personalizadas;

-VS Code: Editor de código-fonte.

# 📚 Considerações finais

O desenvolvimento deste projeto permitiu colocar em prática os conhecimentos adquiridos na disciplina de Desenvolvimento de Sistemas, trabalhando com HTML e CSS para criar uma página temática sobre o Grande Prêmio de São Paulo. Durante a atividade, foram utilizados diferentes recursos de estilização e organização, como Flexbox, Grid, variáveis CSS e responsividade, contribuindo para o aprendizado e aprimoramento das habilidades de desenvolvimento web.
